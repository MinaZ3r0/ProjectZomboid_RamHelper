# ProjectZomboid - RAM Helper

[Project Zomboid - Steam Store Page](https://store.steampowered.com/app/108600/Project_Zomboid/)

Small helper tool that helps you find your PZ folder and help you change your allocated RAM to the game.

![status](https://img.shields.io/badge/status-active-brightgreen) ![license](https://img.shields.io/badge/license-MIT-blue)

## 📖 Overview
Follow the instructions in the script that helps you change your RAM in the game. The guide should take no longer than 5 - 10 mins.

## ✨ Features
- Finds your Project Zomboid folder on your PC
- Checks your Max RAM installed
- Optional backup of .json file

- Frameworks/Libraries: Bash, Powershell

## 🚀 Getting Started
- Download the latest release on the right hand side.
- Extract the .zip file
- Run the "RunMe.bat"
- Follow the instructions
- modify the .json file
- Save the modified file
- Play Project Zomboid
